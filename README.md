## 问题一: 库位初始分配优化

### 问题描述

仓库初始为空，需为65000箱原材料分配初始库位。每箱需指定(货架y, 层z, 列x, 深浅位)，满足层高约束和双深位约束，目标是使未来出库的加权平均时间最小。

### 约束条件 (8项, 全部通过)

| # | 约束 | 说明 |
|---|------|------|
| C1 | 箱数约束 | 65000箱全部分配 |
| C2 | 层高约束 | L1-8仅E1, L9-42仅E1+E3, L43-50全类型 |
| C3 | 双深位约束 | 每库位最多2箱, 偶数占深浅位, 奇数仅浅位 |
| C4 | 均匀填充 | 同(x,z)位置填满14个货架 |
| C5 | 距离排序 | 按物理距离和升序填充 |
| C6 | 消耗排序 | 组内按消耗占比降序分配 |
| C7 | 列宽约束 | 400mm/列 |
| C8 | 层高比例 | 200:400:500 = 2:4:5 |

### 优化算法

**核心思路**: 排序不等式——将"高消耗占比"的材料配对"短物理距离"的库位，得到全局最优。

**步骤**:

1. **生成填充队列**: 所有(x,z)位置按物理距离和 `D = x*400 + H(z)` 升序排列。对每个(x,z)，依次填充14个货架。

2. **材料排序**: 每种箱型组内按消耗占比降序排列。

3. **贪心匹配**: 遍历填充队列，每个位置从允许的箱型中选消耗占比最高的材料:
   - L1-8: 仅E1候选
   - L9-42: E1+E3候选，选消耗最高的
   - L43-50: E1+E3+E4候选，选消耗最高的

4. **双深位处理**: 库存≥2箱时同时占深浅位(同一位置2箱)，奇数余量仅占浅位。

**最优性证明**: 对于任意两个位置A(D₁)和B(D₂)，D₁<D₂，两个材料M₁(消耗c₁)和M₂(消耗c₂)，c₁>c₂。若将M₁放B、M₂放A，总加权时间 = c₁D₂ + c₂D₁；交换后 = c₁D₁ + c₂D₂。差值 = c₁(D₂-D₁) - c₂(D₂-D₁) = (c₁-c₂)(D₂-D₁) > 0。因此高消耗放近距离严格优于反置，贪心匹配即为全局最优。

**时间复杂度**: O(N log N)，N=47600个位置。

## 问题二: 纯出库堆垛机调度优化

### 问题描述

7天内3738个出库订单，7巷道各1台堆垛机并行工作。订单到达时间分散在160小时内，每台堆垛机独立调度其巷道的任务。目标是最小化平均流动时间(完成时刻 - 到达时刻)。

### 调度策略

| 策略 | 规则 | 平均流动时间 | vs SPT |
|------|------|-------------|--------|
| **SPT** | 最短运输时间优先 | **701s** | -- |
| FIFO | 先到先做 | 927s | +32.3% |
| Priority | 消耗占比优先 | 803s | +14.6% |

### SPT最优性

问题二可分解为7个独立的单机调度问题 $1|r_j|\sum (C_j - r_j)$。

在空闲期之间(between idle gaps)，已到达的订单形成一个batch。对每个batch，SPT按$p_j$(运输时间)升序排列最小化$\sum C_j$，等价最小化平均流动时间。这是排队论的经典结论。

**SPT优于Priority的原因**: 消耗占比与运输时间不相关。高消耗材料可能在远处(运输时间长)，Priority让长任务插队反而堵塞短任务。

### 抢占规则

新订单到达时，堆垛机不中断当前任务(必须完成当前取货并返回原点)。返回原点后，重新对队列按SPT排序，挑选最短的任务执行。

### 关键发现

- **临界速度 vx=0.32 m/s**: 当水平速度低于此值时，运输时间超过平均到达间隔(154s)，队列开始堆积
- **7机负载**: 499-560箱/机，利用率16-19%，系统严重空闲(orders spread across 160h, work only 38.5h)
- **Makespan不可优化**: 总工作量38.5h << 160h跨度，所有策略的makespan基本相同

### 结果

| 指标 | SPT | FIFO | Priority |
|------|-----|------|----------|
| 平均流动时间 | 701s | 927s | 803s |
| 中位数 | 289s | 385s | 347s |
| SPT vs FIFO提升 | -- | **24.4%** | -- |

## 问题三: 入库与出库协同优化 (待完成)

### 问题理解

问题一和问题二分别独立处理了"库存分配"和"纯出库调度"。问题三将两者耦合：

- **入库**和**出库**同时进行
- 667条入库任务(5069箱)按表3时间到达(2026-06-01 ~ 2026-06-06)
- 3738条出库任务(来自表2)也需要完成
- 7台堆垛机，7巷道

**核心挑战**: 入库时选择货位不仅影响当次入库时间，还影响该材料后续出库的运输时间。入库和出库形成"复合作业"——堆垛机一次行程可以同时完成一个入库和一个出库。

**复合操作模式(复合作业)**:
1. 堆垛机从原点出发，携带待入库箱子
2. 行驶至出库箱位置，叉取出库箱
3. 行驶至入库位置，放入入库箱
4. 行驶至出口，交付出库箱
5. 返回原点

相比于单独执行(先入库再出库)，复合作业节省了一次空载回原点的时间。

### 关键难点

1. **入库位选择的两难**: 放近处→入库快但可能挤占高频出库材料的黄金位置；放远处→入库慢但保留近处给高频材料
2. **复合作业的路径规划**: 出库位→入库位→出口的顺序影响总时间，需要评估所有可能的出-入配对
3. **动态到达**: 入库任务不是一次性全部到达，需要在线决策
4. **与问题一结果的交互**: 问题一的库位已占满(65000箱/47600库位,利用率136.6% via 双深)，入库箱需要找空深位存放

### 初步思路

1. 从问题一结果找出所有空深位(626个奇数库存留下的空位)
2. 入库5069箱 >> 626空位，需要新增占用策略(可能用到L43-50区等远距离区域)
3. 对每个入库任务，在选择空闲位时考虑: 该材料的消耗占比 × 库位距离(类似问题一但在线)
4. 复合作业用贪心匹配: 空闲时扫描待处理队列，找出库-入库配对使复合路径最短
