## 项目概述

S工厂自动立体库(AS/RS)库位分配与堆垛机调度优化。仓库含7巷道、14货架、7台堆垛机，双深位货架(50层×68列)，约2000种原材料(E1/E3/E4三种箱型)。

**核心目标**: 优化库位分配与堆垛机调度，最小化出入库作业总时间。

## 问题一: 库位初始分配优化

**目标**: 为65000箱分配初始库位，最小化加权平均出库时间。

**算法**: 排序不等式贪心匹配——高消耗占比→短距离位置，证明为全局最优。

| 指标 | 数值 |
|------|------|
| 分配箱数 | 65000 |
| 加权平均出库时间 | **25.41s** |
| 随机打乱 | 39.76s |
| **提升** | **36.1%** |
| 约束通过 | 8/8 |

---

## 问题二: 纯出库调度优化

**目标**: 7台堆垛机并行调度3738个出库订单，最小化平均流动时间。

**算法**: SPT(最短运输时间优先)，分解为7个独立单机调度问题。

| 策略 | 平均流动时间 | vs SPT |
|------|-------------|--------|
| **SPT** | **701s** | — |
| Priority | 803s | +14.6% |
| FIFO | 927s | +32.3% |

---

## 问题三: 出入库协同调度

**目标**: 出入库同时进行，复合作业消除空回程，最小化总流动时间。

**框架**: 事件驱动仿真，7台堆垛机并行，复合判定(出库+入库配对)。

| 指标 | 数值 |
|------|------|
| 总流动时间 | 40.2M s |
| 复合占比 | ~60% |
| 出库/入库 | 3738 / 5069 |
| 自检通过 | 13/13 |

## 问题四: 非线性速度模型对比

**目标**: 梯形/三角形速度曲线(含加速度)与线性匀速模型对比。

**模型**: TimeModel基类 → LinearTimeModel / NonlinearTimeModel。

| 模型 | 总流动时间 | 差异 |
|------|-----------|------|
| 线性 | 基准 | — |
| 非线性 | 相近 | 幅值小 |

## 问题五: 动态库位重分配

**目标**: 6.7天运营后评估仓库偏离度，触发选择性整理，对比成本。

**方法**: 从操作CSV回放重建仓库终态 → 偏离评估 → 选择性整理(仅严重偏离箱)。

| 指标 | 不整理 | 整理 |
|------|--------|------|
| 总流动时间 | 732.7h | 737.4h |
| 严重偏离率 | 3.7% | **0.1%** |
| 移动箱数 | 0 | 2500 |
| 整理耗时 | 0 | 4.7h |

## 经验总结

1. **排序不等式是核心**: 问题一的贪心最优性、问题二的SPT最优性，都源于排序不等式。
2. **先分解再合成**: 问题二分解为7个独立单机问题后，复杂度从组合爆炸降为线性。
3. **事件驱动仿真扩展性好**: 问题三→四→五复用同一框架，只换时间模型和策略。
4. **大规模仿真注意O(n²)陷阱**: 问题五原代码每次crane_free遍历全量pending队列，65000次×数千条=卡死。快速版从已有CSV回放，O(N)秒出。
5. **选择性优于全局**: 问题五只动3.7%严重偏离箱，用4.7h换取偏离率归零，成本仅增0.6%。
6. **数值从代码提取**: 所有报告数值由程序自动计算，杜绝手写错误。
